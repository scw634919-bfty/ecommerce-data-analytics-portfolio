# Data

This project uses the **Clickstream Data for Online Shopping** dataset from the UCI Machine Learning Repository: clicks from an online clothing store, April – August 2008 (165,474 rows). The file is semicolon-separated.

The raw data file is not stored in this repository. To run the notebook:

1. Download the dataset from UCI: https://archive.ics.uci.edu/dataset/553/clickstream+data+for+online+shopping
2. Unzip it and put `e-shop clothing 2008.csv` in this `data/` folder.

The download also includes `e-shop clothing 2008 data description.txt`, which explains the codes (for example, colour 10 = olive and country 29 = Poland).

The notebook reads `../data/e-shop clothing 2008.csv` when it runs from the `notebook/` folder.
