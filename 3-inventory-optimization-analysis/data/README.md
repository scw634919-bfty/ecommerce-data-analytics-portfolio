# Data

This project uses the **Online Retail** dataset from the UCI Machine Learning Repository: transactions from a UK-based online retailer, December 2010 – December 2011 (541,909 rows).

The raw data file is not stored in this repository. To run the notebook:

1. Download the dataset from UCI: https://archive.ics.uci.edu/dataset/352/online+retail
2. Unzip it and put `Online Retail.xlsx` in this `data/` folder.

The notebook reads `../data/Online Retail.xlsx` when it runs from the `notebook/` folder.
